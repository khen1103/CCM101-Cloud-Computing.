## 🌟 Project Overview
Welcome to the final enterprise architecture portfolio! This repository documents the complete end-to-end deployment, network configuration, security hardening, and disaster recovery automation for our private cloud infrastructure.

### 🛠️ Architecture Stack & Technologies:
* **Hypervisor:** Oracle VM VirtualBox (Type 2 Hypervisor) 💻
* **Guest OS:** Ubuntu Server (Headless Linux) 🐧
* **Containerization:** Docker & Docker Compose 🐳
* **Application Layer:** Nextcloud (Latest) ☁️
* **Database Layer:** MariaDB 10.11 LTS 🗄️
* **Security & Automation:** UFW Firewall & Cron-scheduled Bash Backups 🔒🤖
