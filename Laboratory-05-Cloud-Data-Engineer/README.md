# Laboratory 5: The Cloud Data Engineer

## Mission Overview
As a temporary member of the Cloud Data Engineering Team at CloudNova Technologies, this mission focuses on deploying an S3-compatible object storage server (MinIO) using Docker to support a client's photo-sharing application[cite: 1].

## Objectives
* Differentiate between Block, File, and Object Storage[cite: 1].
* Deploy an S3-compatible Object Storage server (MinIO) using Docker[cite: 1].
* Access cloud services via a web interface using port forwarding[cite: 1].
* Create storage buckets and upload objects via the web console[cite: 1].
* Document cloud configurations using Markdown and maintain a GitHub portfolio[cite: 1].

## Tools Used
* **KillerCoda Ubuntu Playground** (Docker environment)[cite: 1]
* **Docker & MinIO**[cite: 1]
* **GitHub** for portfolio documentation[cite: 1]
* **Modern Web Browser**[cite: 1]

## Skills Learned
* Containerizing and managing cloud storage services with environment variables[cite: 1].
* Using port mapping (`-p`) to connect local ports to container web consoles[cite: 1].
* Structuring technical documentation using Markdown[cite: 1].
