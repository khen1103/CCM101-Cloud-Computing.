# ☁️ Laboratory Activity 5: The Cloud Data Engineer

> **Mission Objective:** Deploy an S3-compatible object storage server using MinIO on Docker, create storage buckets, and upload files.

---

## 📌 Mission Overview
As part of the Cloud Data Engineering Team at CloudNova Technologies, this project addresses the core challenge of ephemeral container storage. Web applications cannot safely store persistent files inside ephemeral web server containers. This activity establishes an S3-compatible cloud storage server using MinIO.

---

## 🎯 Objectives & Key Deliverables
- 📦 Differentiate between Block, File, and Object Storage.
- 🐳 Deploy an S3-compatible Object Storage server (MinIO) using Docker.
- 🌐 Access a cloud service via a web interface using port forwarding.
- 📁 Create a storage bucket and upload files to the cloud.
- 📝 Document cloud storage operations using Markdown.

---
