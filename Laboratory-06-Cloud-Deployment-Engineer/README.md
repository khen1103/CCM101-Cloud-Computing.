# ☁️ LABORATORY 06: CLOUD DEPLOYMENT ENGINEER 🛠️
---

## 📌 Mission Overview
In this mission, we moved away from manual single-container commands and learned how to use Infrastructure as Code with Docker Compose. We successfully deployed a two-tier enterprise cloud storage system using a Nextcloud web application connected to a MariaDB database.

## 🎯 Objectives
* Explain what a multi-tier application architecture means.
* Understand the structure and purpose of a docker-compose.yml file.
* Use the Linux nano text editor to create configuration files.
* Deploy a multi-container application (Nextcloud and Database) using Docker Compose.
* Document all deployment steps using Markdown.

## 💻 Commands Executed
* mkdir nextcloud-deployment
* cd nextcloud-deployment
* nano docker-compose.yml
* docker-compose up -d
* docker-compose ps
* docker-compose down

## 💡 Skills Learned
* Structuring multi-tier application architectures.
* Writing Infrastructure as Code configurations using YAML.
* Managing multiple containers and internal networking with Docker Compose.
* Creating technical documentation and managing projects using GitHub.
